# Pal Antojo Shopify frontend

Frontend-only copy of the Pal Antojo Shopify theme for mobile-first redesign work.

## Source

Copied from `shopify-theme-copy-horizon` on the `codex/shopify-mobile-redesign` branch.
The source theme remains untouched.

## Included

- Liquid layouts, templates, sections, blocks, and snippets
- Theme configuration and English/localized copy
- CSS, JavaScript, type definitions, and SVG interface icons
- Lightweight labeled SVG placeholders for custom raster imagery

## Excluded

- Original PNG, JPG, JPEG, WebP, GIF, and AVIF files
- Business trackers, reports, registration documents, and backend utilities
- Shopify product media, which is provided dynamically by the connected store

See `assets/IMAGE_PLACEHOLDERS.md` for the full image inventory and the mapping used by the copied theme.

## Redesign target

The next pass will focus on the mobile storefront. All marketing and interface copy should remain in English, while brand and product names such as Pal Antojo, Adobado, Jicama, Taro, and Colitakis remain unchanged.
