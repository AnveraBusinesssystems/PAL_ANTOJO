# Pal Antojo homepage hero video

Upload your final video as:

`media/pal-antojo-hero-mobile.mp4`

The storefront homepage already references this path. Use a vertically composed (9:16 or 4:5), muted, short looping MP4. Recommended: H.264 video, no required audio, optimized for mobile connection speeds, with the product visible within the central crop.

Playback: autoplay + muted + loop + playsinline. The homepage displays a branded fallback if no video exists or playback fails. Users who prefer reduced motion should not be forced to watch moving content.

The video is intentionally **not bundled** because the brand footage has not yet been provided. Do not replace this README with copyrighted or unrelated footage.
